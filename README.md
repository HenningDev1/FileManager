<h1 align="center">File Manager</h1>

<p align="center">A clean, fast file manager for Windows with a macOS-inspired look — rounded, calm and keyboard friendly.<br>
Built with C# / .NET 10 and Avalonia.</p>

## Features

- **Dual pane mode** (F6) — copy/move between panes with one click, drag & drop, Tab switches panes
- **Batch operations** — a floating action bar appears when several items are selected: copy, cut, copy/move to other pane, batch rename, zip, delete
- **Batch rename** with live preview — find/replace (or regex), patterns like `Holiday_{n}`, counters, dates, case, new extension
- **Quick search** — instant filter of the current folder, plus a parallel deep search (wildcards, type and size filters, all drives)
- **Duplicate finder** — compares by content (size → partial hash → SHA-256) and recognises copy names like `photo_1.jpg`, `photo (2).jpg`, `photo - Copy.jpg`, `Kopie von photo.jpg`. Suggests which copy to keep; **never deletes automatically** — you review and confirm, and files go to the Recycle Bin
- **Storage dashboard** (TreeSize-style) — drive usage, folder tree sorted by size with share bars, largest files, space by file type. Skips junctions and cloud-only OneDrive files
- **Previews** — images, PDFs (page by page), videos (frame strip + scrubbing), audio metadata, text/code, ZIP contents, folders, plus Windows shell thumbnails for everything else
- **Customisable** — 8 colour themes, accent colours (presets or any hex), any installed font, text size and corner roundness
- Native Windows copy/move dialogs with conflict handling, Recycle Bin, ZIP/unzip, properties, “open terminal here”, file system watching

## Download & install

Grab `FileManager-Setup.exe` (installer) or `FileManager.exe` (portable) from the [Releases](../../releases) page.

The installer is per-user (no admin rights). Running it again when File Manager is already installed offers **Reinstall/Update** or **Uninstall**. It also registers in *Windows Settings → Apps*, so it can be removed from there too.

## Repository layout

```
assets/        App icon (generated by build/make-icon.ps1)
build/         Build scripts
src/
  FileManager/         The app (Avalonia)
  FileManager.Setup/   Installer / uninstaller
  Shared/              Install logic shared by both
artifacts/     Build output — not committed
release/       Finished packages — not committed, attached to GitHub Releases
```

## Building

Requires the .NET 10 SDK on Windows.

```powershell
# Run from source
dotnet run --project src/FileManager

# Build release packages into release/
powershell -ExecutionPolicy Bypass -File build/build.ps1 -Version 1.0.0
```

## Keyboard shortcuts

| Keys | Action |
| --- | --- |
| Ctrl+F / Ctrl+Shift+F | Filter folder / deep search |
| F6, Tab | Dual pane, switch pane |
| Ctrl+P | Preview panel |
| Ctrl+L | Type a path |
| F2 / Ctrl+R | Rename / batch rename |
| Del / Shift+Del | Recycle Bin / delete permanently |
| Ctrl+C, X, V | Copy, cut, paste |
| Ctrl+Shift+N | New folder |
| Alt+← / → / ↑, Backspace | Back / forward / up |
